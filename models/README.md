# Model architecture files

These are the architecture files referenced by `pipeline.py`, organized under `models/` so the original import shape (`models.resnet`, etc.) remains intact.

Source implementation: `https://github.com/StoryMY/take-off-eyeglasses`

The original source comments attribute parts of the architecture to PyTorch AdaIN, CycleGAN/pix2pix, and Justin Johnson's fast neural style transfer implementation.
